# ROMELL TEXTIL · Sitio web 2026

Sitio de ROMELL TEXTIL (Puebla, México): telas de punto piqué, cardigán, chiffón y felpa.
Funciona en celulares (iPhone y Android), iPad y tablets, laptops y monitores grandes.

## Publicar en GitHub Pages

1. Crea un repositorio nuevo en GitHub, por ejemplo `romell-web`.
2. Sube **todo el contenido de esta carpeta** a la raíz del repositorio
   (`index.html` debe quedar en la raíz, junto a `css/`, `js/` y `media/`).
3. En el repositorio entra a **Settings → Pages**.
4. En **Source** elige **Deploy from a branch**, rama `main` y carpeta `/ (root)`. Guarda.
5. En 1 o 2 minutos el sitio queda en `https://TU-USUARIO.github.io/romell-web/`.

## Formulario de contacto

- En **GitHub Pages** no se ejecuta PHP: el formulario abre WhatsApp (221 184 1803) con el mensaje ya escrito.
- En el **hosting definitivo con PHP**, el formulario envía el correo a ventas@romelltextil.com con `enviar.php`.

| Archivo | Página |
|---|---|
| `index.html` | Inicio |

| `soluciones.html`, `propuesta.html`, `politica-calidad.html` | Soluciones y detalle |
| `catalogo.html`, `producto-*.html` | Catálogo con filtro por color y fichas de cada tela |
| `contacto.html`, `aviso-privacidad.html` | Contacto y aviso de privacidad |
| `sustentable.html` | Hilos preteñidos y cuidado del agua |
| `css/styles.css`, `js/main.js` | Estilos y funciones de todo el sitio |
| `media/` | Fotos, videos e íconos |
